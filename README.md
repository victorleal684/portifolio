# Victor Leal Portfolio

A one-page cinematic black portfolio website in English.

## How to edit

- Open `index.html` and replace the placeholder links in the **Selected Work** section.
- In the **Demo Reel** section, replace the placeholder card with your video embed.

Example YouTube embed:

```html
<iframe width="100%" height="430" src="https://www.youtube.com/embed/YOUR_VIDEO_ID" title="Victor Leal Demo Reel" frameborder="0" allowfullscreen></iframe>
```

## Files

- `index.html` — website structure and text
- `styles.css` — visual style
- `script.js` — mobile menu and scroll animation

## Publishing options

You can upload these files to Netlify, Vercel, GitHub Pages or any basic hosting service.
